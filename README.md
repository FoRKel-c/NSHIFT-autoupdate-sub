# NetShift Watchdog

Автоматический скрипт-сторож для OpenWrt (NetShift), который отслеживает доступность интернета или конкретного домена и автоматически обновляет подписку NetShift при сбое соединения.

---

## Основные возможности

* **Интерактивный инсталлятор**: Удобное меню выбора целевого домена (Telegram API, YouTube, Google, Discord, Cloudflare) или ввод собственного.
* **Гибкая настройка интервала**: Выбор частоты проверки сети в минутах.
* **Защита от холостой работы**: Скрипт проверяет наличие запущенного процесса netshift. Если служба выключена, проверки не выполняются.
* **Двухэтапная проверка**: Исключает ложные срабатывания при кратковременных микросбоях сети (повторный запрос через 5 секунд).
* **Бесшовное автообновление**: Скрипт сам сверяет версию с GitHub и автоматически обновляет себя при выходе новых релизов.
* **Фильтрация ввода**: Автоматическая очистка протоколов https://, http://, слэшей и скрытых спецсимволов при вводе кастомных доменов.
